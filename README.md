# MERN Stack Internship - Task 3

## 📌 Project Overview

This project is a full-stack MERN To-Do Application developed as part of my MERN Stack Internship. It demonstrates complete CRUD (Create, Read, Update, Delete) operations by integrating React.js, Express.js, MongoDB, and Mongoose.

Users can add, view, edit, update, and delete tasks, making it a complete task management application.

---

## 🚀 Features

- Add new tasks
- View all tasks
- Edit existing tasks
- Update tasks in real-time
- Delete tasks
- React Hooks (useState & useEffect)
- REST API Integration using Axios
- MongoDB Database Integration
- Dynamic UI Updates

## 📡 REST API Endpoints

### Create Task

```
POST /add
```

### Get All Tasks

```
GET /tasks
```

### Update Task

```
PUT /update/:id
```

### Delete Task

```
DELETE /delete/:id
```
